# Skills

Skills available to Cursor and Claude Code, one folder per skill with a `SKILL.md`. Committed as plain files.

They came from [agent-kit](https://github.com/rcrdk/agent-kit) and were copied in. There is no submodule — add, edit, or delete skills here directly, and mirror anything reusable back into agent-kit.

- **Cursor:** `.cursor/skills` → `agents/skills/`
- **Claude Code:** `.claude/skills` → `agents/skills/`

See [agents/README.md](../README.md).
